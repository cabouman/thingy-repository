The front page of the Thingy Repository: small apps (thingys) built by
Friends of Charlie (FoC). The page reads the collection and shows one
tile per approved thingy, sorted by likes.

This Space is a deployment mirror. The source lives at
https://github.com/cabouman/thingy-repository and every push to main
there redeploys this Space via a GitHub Action.

Submissions: email the link to your Space to Charles.Bouman@gmail.com
with the subject "Thingy submission: [name]". See the page itself for
the full instructions.

Maintained by Charlie Bouman (cabouman).
