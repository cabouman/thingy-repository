The frame for a thingy that already lives somewhere else on the web -
GitHub Pages, a personal site, anywhere. The frame is a Space, so the
thingy gets a tile, an icon, and likes on the repository page, while
the thingy itself stays where it lives.

To make one: duplicate this Space, then set four things:

1. The `THINGY_URL` line in `index.html` - the thingy's address.
2. The `<title>` in `index.html` and the `title:` above.
3. `icon.png` - the square tile image.
4. `thingy_author:` above - the tile's "by" name.

This example frames Charlie's Joke Machine from its GitHub Pages home.
A framed thingy stays as alive as its home page: if the page moves or
goes down, the frame shows nothing.
